# Kumpulan Tugas Latihan Mandiri Pemrograman Web

Berikut adalah daftar file latihan mandiri yang telah diunggah:

- [Kalkulator PHP](kalkulator.php) - Program kalkulator sederhana dengan penanganan pembagian nol.
- [Daftar Mahasiswa (Array)](mahasiswa_array.php) - Menampilkan data array mahasiswa ke dalam tabel HTML beserta rata-rata nilai.
- [Fungsi Konversi Nilai](konversi_nilai.php) - Fungsi PHP untuk konversi nilai angka ke huruf mutu sesuai RPS.
- [CRUD Database (PDO & Prepared Statement)](crud_pdo.php) - Form input dan tabel data mahasiswa menggunakan koneksi PDO yang aman dari SQL Injection.
